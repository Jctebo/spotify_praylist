# Release 0.4.2.1 - rosary-witness-permissive-validation

- Status: Shipped
- Created Date: 2026-08-20
- Last Updated: 2026-08-20
- Depends On: 0.4.2.0

## Scope

- Production verification of v0.4.2.0 showed valid LLM Rosary responses falling back because validation required the full witness string and repeated mentions.
- Accept a natural core-name witness mention while preserving the requirement that supplied saint context appear in the package.

## Research

- Public production sidecars for August 20 and 21 recorded `fallback_deterministic` with witness-validation errors despite producing valid observance-aware fallback prose.
- The failure was isolated to `_require_saint_witness()` in `jobs/publish/rosary_reflections.py`.

## Plan

- Match both the full witness and a normalized core name before the comma/title suffix.
- Require one natural witness mention rather than a fixed repeated count.
- Add focused regression coverage and rerun the publish/audio suite.

## Progress

- Focused tests: 20 passed.
- Publish/audio integration tests: 88 passed.
