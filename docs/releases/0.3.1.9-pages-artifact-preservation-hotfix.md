# Release 0.3.1.9 - Pages Artifact Preservation Hotfix

Date: 2026-05-09
Version: 0.3.1.9
Status: Shipped
Last Updated: 2026-05-09
Branch: hotfix/pages-artifact-preserve
Depends On: 0.3.1.8

## Scope

### Problem
- The devotional image workflow was publishing its own GitHub Pages artifact from a devotional-only tree.
- That artifact could overwrite the podcast homepage and feed, which left the root Pages URL returning a 404.

### Goal
- Preserve the podcast site whenever the devotional image workflow publishes.
- Keep the devotional gallery under `/devotional/DCIM` without disturbing the rest of the Pages tree.

### Solution
- Restore the published audio archive into the build tree.
- Seed the Pages artifact from `docs/` before overlaying devotional images.
- Continue publishing devotional output under `/devotional/DCIM`.

### Verification
- Confirmed the live Pages root and `podcast.xml` return `HTTP 200` after republishing the podcast workflow.
- Confirmed the workflow diff only touches `.github/workflows/daily_devotional_image_remote.yml`.
