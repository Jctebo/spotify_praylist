## Plan
### Summary and architecture
- Own three request attempts per provider, retry only connection/timeouts and HTTP 408/409/429/5xx; use 5/10-second backoff and fresh OpenAI clients with SDK retries disabled.
- OpenAI: 15-second connect timeout, 300-second read/write timeout for long spoken blocks. ElevenLabs: 15-second connect, existing 120-second read timeout.
- Log exception/cause class names, HTTP status, and a validated machine error code; omit exception prose, response bodies, headers, URLs, and credentials. Preserve provider fallback and fail on complete exhaustion.

```text
fragment cache -> provider request -> success -> existing assembly
                         |
                 transient failure -> bounded retry
                         |
                 exhausted/permanent -> next provider -> fail if all fail
```
