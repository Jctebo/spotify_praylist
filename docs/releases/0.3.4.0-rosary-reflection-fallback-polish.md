## Scope

This release improves the Daily Rosary reflection experience after the first generated episodes showed two issues: the spoken pause between the mystery fruit and the reflection could be too short, and fallback reflections were too plain when Gospel-grounded OpenAI generation could not run.

## Research

The live Rosary sidecars showed that the first reflections had used the deterministic fallback text. The audio fragment text also showed that the fruit and reflection labels were separated only by a newline, which was not always enough for a reliable TTS pause.

## Plan

- Add a stronger text boundary between the fruit line and the reflection line in Rosary reflection audio fragments.
- Keep Gospel-grounded OpenAI reflections as the preferred path.
- Add a second OpenAI path that writes season-grounded reflections when Gospel text is unavailable or Gospel generation fails.
- Keep a final generic fallback with the same approximate shape and length as generated reflections.
- Update tests for pause formatting, seasonal generation, and generic fallback behavior.

## Progress

### Completed Work
- Added punctuation and a blank line before the spoken `Reflection:` label in Rosary reflection audio fragments.
- Expanded Rosary reflection generation into three tiers: Gospel OpenAI, seasonal OpenAI, then generic season-aware fallback.
- Updated prompt rules and fallback text so each reflection is a four-sentence paragraph that describes the mystery, describes the fruit, and repeats both naturally.
- Raised the reflection length cap to fit the richer spoken format while still validating generated output.
