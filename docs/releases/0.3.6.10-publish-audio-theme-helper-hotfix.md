## Scope

Fix the remote `Publish Prayer Audio` failure introduced by the shared daily theme release. The workflow failed in `jobs.publish.run_audio_pipeline` with `NameError: _join_with_and is not defined` while building the shared theme for a day with multiple calendar names.

## Research

The GitHub Actions run `27581122407` failed in the `Publish audio files and RSS feed` step after dependency installation. The log showed:

```text
audio_pipeline start base_url=https://Jctebo.github.io/spotify_praylist audio_base_url=https://audio.orapronobis.media target_dates=2026-06-16 contracts=6
ERROR: name '_join_with_and' is not defined
```

`jobs/publish/daily_liturgical_context.py` used `_join_with_and()` in `_shared_theme_sources()` for multiple calendar celebration names, but the helper only existed in sibling modules such as `daily_intro.py`, `contracts.py`, `liturgical_announcement.py`, and `rosary_reflections.py`.

## Plan
