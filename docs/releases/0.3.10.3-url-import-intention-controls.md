Status: Pull request open; ready to merge

Last Updated: 2026-07-25

## Scope

### Problem
- The URL importer replaces `(mention request here…)` with the spoken sentence `Pause here to mention your request.`
- TTS therefore reads the instruction aloud instead of giving the listener a sacred bell and silent space for a personal intention.

### Audience
- Primary: people praying imported novena audio.
- Secondary: maintainers importing a new Catholic Novena App source.

### Current Status Quo
- Structured novena blocks already support a non-spoken `sacred_bell` followed by a 5,000 ms `personal_intention` pause.
- The importer currently emits only ordinary text for this source marker, so the existing structured controls are bypassed.

### Goal
- Every future URL import with the verified source marker creates a bell and five-second personal-intention pause at the marker’s exact position.
- The legacy readable `sections` text omits the non-spoken instruction and stays consistent with the structured audio block.

### Constraints
- Preserve the surrounding prayer text, canonical-prayer expansion, grouping, and fragment reuse.
- Do not alter bell synthesis, pause duration, providers, voices, or existing checked-in contracts in this fix.
- Match only the verified importer source marker and retain conservative behavior for unfamiliar wording.

### Narrow Wedge
- Convert the importer’s existing `mention request here` replacement from textual speech into structured controls while compacting URL-imported day sections.

### Non-Goals
- Reimporting or regenerating existing contracts/audio.
- Broadening prayer-text normalization or changing manually authored novenas.

### Risks And Unknowns
- The marker can occur mid-paragraph, so splitting must preserve text on both sides and control order.
- `sections` and `blocks` can drift unless both representations are derived from the same cleaned text.

### Recommended Next Step
- Plan the smallest importer transformation and regression coverage around the existing compact-block path.

## Research

### Relevant Files
- `jobs/novena_contracts/url_import.py`: local importer currently substitutes the marker with spoken text in `_local_tts_resolution`, then builds compact `blocks` in `_compact_template_sections`.
- `tests/test_novena_url_import.py`: synthetic source-page importer tests, including an existing fixture with `(mention request here…)`.
- `jobs/novena_contracts/validators.py`: validates `audio_cue` and `pause` block parts.

### Findings
- The exact source marker is defined by `TTS_PLACEHOLDER_RE` and is transformed before compaction.
- Existing block parts already support the desired `audio_cue`/`pause` shape, but `_text_to_parts` only receives plain text after the source instruction has become speech.
- The cleanest compatible seam is to preserve a non-spoken internal marker through local resolution, remove it from legacy section text, and turn it into two control parts during compaction.

## Plan

### Summary
- Replace the importer’s spoken pause prompt with an internal, non-spoken intention marker.
- Convert that marker to `sacred_bell` then a 5,000 ms `personal_intention` pause when constructing structured block parts.

### What Already Exists
- `_compact_template_sections` already creates `blocks[].parts[]` and canonical prayer fragments.
- Contract validation and the audio renderer already understand `audio_cue: sacred_bell` and `pause: personal_intention`.

### Architecture

```text
source marker -> internal importer marker -> cleaned legacy section text
                                      \-> block parts: text -> sacred_bell -> pause -> text
```

### Concrete Changes
- Edit `jobs/novena_contracts/url_import.py` to keep the source marker non-spoken, split it into structured controls during block compaction, and remove the old OpenAI wording direction.
- Edit `tests/test_novena_url_import.py` to verify placement, absence from legacy sections, five-second duration, and block/section consistency.
- Update this release artifact with implementation, QA, and release evidence.

### UX And States
- No UI change. Imported audio gives the bell and silent personal-intention space; readable text shows only the prayer prose.

### Implementation Phases
#### Phase 1: Represent the source marker safely
- Edit `jobs/novena_contracts/url_import.py`.
- Preserve the marker through local normalization without producing speakable text, and ensure OpenAI cannot replace it with spoken prose.
- Verify with focused importer tests.
- Rollback: restore the previous textual substitution.

#### Phase 2: Emit structural controls
- Edit `jobs/novena_contracts/url_import.py`.
- Split marked text into text/control/text parts in `_compact_template_sections`; use one `sacred_bell` then one 5,000 ms `personal_intention` pause per marker.
- Verify contract validation on the synthetic import.
- Rollback: remove the internal-marker branch.

#### Phase 3: Lock in regression coverage
- Edit `tests/test_novena_url_import.py`.
- Assert the pre-marker and post-marker prose is retained, no spoken prompt appears in sections or parts, and controls appear in order for all repeated day blocks.
- Run focused importer tests and relevant novena contract tests.

### Failure Modes
- Mid-sentence text is lost or reordered: exact text-before/text-after assertions fail.
- A control has an invalid shape: contract validation fails.
- A future source marker is spoken: regression asserts no textual pause prompt remains.

### QA And Test Matrix
- Import fixture with the exact source marker across nine days.
- Validate every imported block includes `sacred_bell` immediately followed by a 5,000 ms `personal_intention` pause.
- Confirm legacy sections and block text omit the marker and its old spoken replacement.
- Run `python -m unittest tests.test_novena_url_import tests.test_novena_contracts` and `git diff --check`.

### Rollout Notes
- This affects future URL imports only; existing contracts remain unchanged until deliberately reimported or migrated.

### Not In Scope
- Bulk reimports, published audio regeneration, and broader phrase matching.
