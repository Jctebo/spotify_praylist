## §2 Plan

Client (`app/worker/src/client.ts`) + dress (`app/worker/src/ui.ts`) only.

1. HEAD COUNT = UNPLAYED: in `opnSetHtml609`, the head's meta span becomes `data-p615count="BLOCK"` and reads the block's UNPLAYED count, computed by a new helper in the opn…615 family (`opnCounts615`) over the RUN's tracks as painted: available tracks only; unplayed = `(kind==='podcast' ? !t.listened : !isPlayedDesc(t, presentedDateStr()))`. Occurrence copies count individually (they stand as separate run entries and `isPlayedDesc` reads their own keys). The count discipline is named: AVAILABLE ONLY — "nothing to play, nothing to mark" (the `blockPlayedCounts` precedent), with podcasts read through their own store's flag (the `unplayedOnly` precedent).
2. A DISC PER HEAD: the head gains a disc span in the played-dot dress, seated between the name and the count: class `"played-dot p615disc"`, `data-p615disc="BLOCK"`, `aria-hidden`. States: while unplayed > 0 → the hollow ring (the unplayed dress, NO `.on`); when the block's available total > 0 AND unplayed == 0 → grey: class `"all"` and a `ui.ts` rule `.p609sethead .p615disc.all::after { background: var(--muted); border-color: var(--muted); }` plus head-scoped sizing so the 44px card-row box does not swell the head (`.p609sethead .p615disc { flex:0 0 auto; width:20px; height:20px; margin:0; cursor:default; }`). The disc is a span — paint inside the head, never a separate control; the head stays the one tap target.
3. LIVE UPDATE: extend `refreshPlayedChrome()` with a head pass: for each `[data-p615disc]` element in view, recompute its block's `{total, unplayed}` from `state.dayDescs` grouped by `(x.block || 'Episodes')` with the same reads (`opnBlockCounts615`, built on `opnCounts615`), set the sibling `[data-p615count]` text and toggle the disc's `"all"` class. Recompute from state (never increment counters) — the pass is idempotent like the passes beside it. ALSO add a closing `refreshPlayedChrome()` call at the end of `writePodMarkQuiet` so a podcast completion moves the head in the same act (guarded inside `refreshPlayedChrome` already: no date/no view → return). If the harness shows the dayDescs copy's `listened` flag does not flip on that path, STOP and report the evidence instead of inventing a second read — the coordinator decides.

PLAY ALL DISC OFF: the set's Play All row loses the playbtn disc: the row stands as a plain act — a button with NO playbtn class and NO disc element, carrying `data-queue="__all"` and the text "Play All" (the `.row.p604exphead` wrapper kept — harness-v609 leg checks set children by that class).
