## §1 Scope (Scope + Plan, compressed — streamlined small-release path)

John amended the release by voice call (Ora thread, 2026-11-23 09:00 CT): **"Let's just get rid of the text not available at all" · "Not needed"** — REMOVAL, not rename. The amendment supersedes the registered rename; no replacement wording stands anywhere it pointed.

This release, in `app/worker/src/client.ts` only:

- **The fold is deleted.** In `trackCard`'s available branch, the meta composition loses its final term `+ (noText ? ' · Not available in the app yet' : '')`. The meta ends at the novena span / " · episode file" + duration segment. `noText` itself stays — the Read control keys on it (a no-text row still carries no Read control).
- **The reader's failed-fetch body changes.** `openRead`'s catch no longer paints the struck phrase into the reading view; it paints **"The episode's text could not be loaded."**
- **Nothing else moves.** The genuinely-unavailable own card (`metaU`) keeps "Not available in the app yet" verbatim — there the phrase is true. The v624 "Not available today" / still-checking external line is untouched; the bare "Not available" strings elsewhere are untouched; the `index.ts` API error payloads (lowercase "episode audio/text not available in the app yet", server 404 bodies, never painted as the UI phrase) are untouched.

Base: the v626 shipped tree, commit dbf0c21 (pin ora-pro-nobis-v626-1). Branch release/v627. No migration, no server change, no deploy-shape change.

## §2 The defect + grounded cause

John's screenshot (2026-11-23 08:57 CT) showed two playable own rows in the Afternoon block — "Auxilium Christianorum" and "11/23 - Pope St. Clement I", each with artwork (the second with a 1:42 duration) — carrying "Plays here · episode file · ⟨dur⟩ · Not available in the app yet". The rows play in the app; the trailing words read as if the episode itself were missing.

Grounded cause, verified firsthand on the base tree: the v363 §2.3 no-text fold. In `trackCard`'s available branch the meta composition ended with `+ (noText ? ' · Not available in the app yet' : '')`, where `noText = !(t.hasText && t.textUrl)` — a statement about the episode's **text** (transcript), appended to the same meta line that announces the **audio** ("Plays here · episode file"). A text fact painted in the audio's sentence reads as an availability verdict on the episode. The same phrase also stood as `openRead`'s failed-fetch body, where it was equally wrong in the other direction: a fetch failure is a load error, not an absence.

The phrase has exactly one true home on this surface: `metaU`, the genuinely-unavailable own card, where the episode itself does not stand. That site is kept verbatim, comment and all.
