# Scope: Podcast shortcuts on Pages

## Problem
The published daily prayer Pages header still exposes only the RSS feed, and the podcast panel repeats only that feed shortcut. Visitors need direct access to Ora Pro Nobis on Spotify and the RSS feed from the top of the page.

## Goal
Replace the old single top shortcut with clear Spotify and RSS links. Make both destinations available in the podcast panel too.

## Constraints
- Spotify must link to the Ora Pro Nobis show already referenced by repository contracts.
- RSS remains the site's `podcast.xml` feed.
- Preserve prayer-time shortcuts generated from the latest `prayers.json` playlist groups.
- Keep external Spotify links safe for new-tab navigation and links accessible on mobile.

## Success criteria
- Header has visible Spotify and RSS links.
- Podcast panel offers both links.
- Build artifact test asserts the links and destinations.
- Changes are reviewed, deployed, and verified on the live Pages site.
