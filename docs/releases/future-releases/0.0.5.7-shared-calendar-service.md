# Release 0.0.5.7 - shared-calendar-service

- Status: Future
- Depends On: 0.0.5.6

## Purpose
- Extract the feast-day and novena calendar logic into a reusable shared service.
- Produce a structured calendar output object that can be consumed by the prayer runner and the devotional image job.

## Scope
- Calendar computation
- Feast-day window selection
- Saint and intention selection
- Shared output contract for downstream consumers

## Not In Scope
- Rebuilding the other prayers
- Changing the Morning Prayer contract shape
- Reworking the devotional image render logic itself

## Success Criteria
- Morning Prayer can consume shared novena output if it exists.
- The devotional image job can consume the same shared calendar output.
- No duplicated calendar logic remains in the consumer jobs.
