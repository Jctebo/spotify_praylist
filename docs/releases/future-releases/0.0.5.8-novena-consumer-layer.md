# Release 0.0.5.8 - novena-consumer-layer

- Status: Future
- Depends On: 0.0.5.7

## Purpose
- Make novena a reusable input that consumer jobs can read without owning the generation step.

## Scope
- Read shared novena output from disk or cache
- Attach novena output to Morning Prayer when available
- Feed the devotional image job from the same shared output

## Not In Scope
- Generating novenas inside Morning Prayer
- Rebuilding the other prayers
- Changing the shared calendar rules

## Success Criteria
- Morning Prayer only uses novena when the shared output is already present.
- No job generates novena twice.
- Downstream consumers agree on the same novena data.
