# Release 0.4.11.0 - watch-queue-lower-label-layout

- Status: SHIPPED
- Created / updated: 2026-09-30

- Source: user feedback based on the current Galaxy Watch face layout.

## Scope

### Problem
- Ongoing generated watch queue pictures need to reserve clear space at the top for the watch's date/time display, as in the user's current watch-face photo.
- The devotional subject should retain its current large, centered composition. Only the locally overlaid devotional title/subtitle should move to the bottom so neither competes with the clock.

### Audience
- Primary user: operator using generated devotional watch wallpapers in the watch queue on a Galaxy Watch Classic.
- Secondary stakeholders: the scheduled wallpaper generator and the existing upload/rotation workflow.

### Current Status Quo
- Watch art prompt reserves the upper 38% for devotional title/subtitle and positions the devotional subject below it.
- Watch renderer currently puts title/subtitle at 12% height over a top vignette, which conflicts with the clock-safe region demonstrated in the user's photo.
- Each routine generation creates a new dated watch wallpaper, so changing prompt and renderer updates ongoing queue entries without making a one-off picture.

### Goal
- Future watch-queue images consistently keep the upper 35% visually quiet and dark for the watch clock/date.
- Devotional subject keeps its existing prominent centered scale and composition; exact title and subtitle render legibly at the bottom of the image within the circular safe area.
- Phone wallpapers, queue naming, scheduling, and rotation behavior remain unchanged.

### Constraints
- Apply the composition on every future scheduled/manual watch generation through the shared watch prompt and deterministic renderer.
- Preserve square 1024x1024 JPEG output, exact devotional text, circular safe-area fitting, OCR/local QA, and vision QA.
- Do not invoke production generation, OneDrive uploads, or queue rotation during implementation.

### Narrow Wedge
- Revise the watch-only art prompt only to reserve the upper 35% for clock/date UI while keeping the devotional subject large and centered; move only the overlaid labels.
- Move watch title/subtitle overlay to a bottom-aligned block that fits the circular chord, without scaling down or repositioning the centered devotional subject; update local OCR/QA windows and regression tests to validate that location.

### Non-Goals
- Editing an individual image or existing queued/current OneDrive assets.
- Changing phone image composition or overlays, watch device configuration, folder names, generation cadence, or rotation logic.
- Adding clock/date text into artwork; the real watch face supplies that UI.

### Risks And Unknowns
- Long labels near the bottom have less circular chord width; renderer must shrink/wrap them safely and tests must cover long labels without clipping while preserving the art composition.
- Future generated art may place nonessential details in the clock-safe area despite instructions; QA should explicitly inspect top space and text overlap.

### Recommended Next Step
- Update the watch prompt, bottom-label renderer, watch OCR/vision QA, and focused regression tests; run the wallpaper contract/render/pipeline tests, review the diff, and do not run production storage workflows.

## Research

- `jobs/novena/devotional_image_contract.py::build_art_prompt` defines the reusable per-variant art composition prompt. Its former watch branch reserved upper 38% for overlaid labels and pushed the devotional subject below that area.
- `jobs/novena/devotional_wallpaper_render.py::overlay_wallpaper_text` used a top vignette and placed exact title/subtitle labels at 12% height. `_draw_centered_label` already adjusts text to the watch circular chord.
- Watch OCR used to read title from 12%-46% and subtitle from 26%-40%; vision QA checked overlap and title correctness but did not require a clock-safe upper band or lower label block.
- `tests/test_devotional_wallpaper_contract.py` asserts the prompt composition. `tests/test_devotional_wallpaper_render.py` covers dimensions, safe-circle width, long labels, OCR, and local QA; watch-specific location assertions can be added there.
- Scheduled generation uses the same shared renderer/prompt for watch queue images; changing these paths affects ongoing future generation while preserving phone behavior and rotation.

## Plan

### Summary
- Keep the generated devotional subject large and centered, reserve the top 35% of future watch art as calm clock/date space, and move only the exact overlaid title/subtitle to the bottom.
- Use the existing per-variant prompt and Pillow renderer so the recurring queue generation picks up the layout without storage or scheduling changes.

### What Already Exists
- `build_art_prompt` supplies separate phone/watch composition instructions.
- `overlay_wallpaper_text` has independent phone/watch layout branches; `_draw_centered_label` wraps and fits exact wording against a circular chord.
- Watch OCR and local QA validate exact title/subtitle text; vision QA inspects artwork before storage.

### Architecture
```text
watch queue generation
  -> watch art prompt (centered subject + top clock-safe region)
  -> generated square artwork
  -> exact title/subtitle overlay at bottom of circular display
  -> OCR + vision QA
  -> existing queue upload/rotation
```
- Only watch-specific behavior changes. The renderer continues using centered `ImageOps.fit` and does not shrink or recrop the subject to create a label band.

### Concrete Changes
- `jobs/novena/devotional_image_contract.py`: update watch branch of `build_art_prompt` to reserve the top 35% for clock/date, keep the devotional subject large and centered, and state that labels are added separately at the bottom.
- `jobs/novena/devotional_wallpaper_render.py`: preserve artwork scaling/cropping; replace the watch top vignette/title coordinates with a restrained bottom contrast fade and bottom-aligned title/subtitle coordinates within circular safe area; adjust watch OCR crops and `vision_qa` to require top clock-safe space and lower overlay placement.
- `tests/test_devotional_wallpaper_contract.py`: assert top clock-space, centered subject, no instruction to push subject below a label area, and text-free generated art.
- `tests/test_devotional_wallpaper_render.py`: assert watch text pixels occur in the lower band, the upper 35% receives no overlay, long labels fit within the lower circular chord, and phone behavior/output contract stays unchanged.

### UX And States
- No interactive UI. New watch queue images show the clock/date over quiet space at the top, the unchanged centered devotional art, and exact devotional labels at the bottom.
- Existing OCR/vision rejection and retry handling remain the failure path if text clips, art violates the composition, or the top is not clock-safe.
