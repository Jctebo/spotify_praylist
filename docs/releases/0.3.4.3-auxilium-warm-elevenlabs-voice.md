# Release 0.3.4.3 - Auxilium Warm ElevenLabs Voice

Status: Scoped
Branch: enhancement/saint-anthony-colon-tts-cleanup
Created: 2026-06-05

## Scope

### Problem
- Auxilium Christianorum audio is using an ElevenLabs custom voice that sounds too quiet for daily prayer listening.
- The current contract has a warm-sounding OpenAI fallback for short response roles, but the main Auxilium body still depends on one ElevenLabs `voice_id`.
- The listener experience should feel reverent, warm, intelligible, and loudness-consistent without manually adjusting volume between episodes.
- Why now: Auxilium Christianorum is already live as a daily Ora Pro Nobis episode, and prior response-audio cleanup left dedicated ElevenLabs voice selection as the obvious follow-up polish.

### Audience
- Primary user: the maintainer choosing and publishing the daily Auxilium Christianorum audio.
- Secondary stakeholders: daily listeners praying along through the podcast/Spotify feed, especially in noisy or low-volume listening contexts.

### Current Status Quo
- `config/publish/contracts/auxilium-christianorum.json` enables audio with ElevenLabs first and OpenAI fallback.
- The main ElevenLabs provider uses `voice_id` `2NfTQuOn6dRQvgKuC2le`, `model_id` `eleven_multilingual_v2`, stability `0.5`, similarity boost `0.75`, speaker boost on, and speed `1.0`.
- Auxilium `versicle` and `response` fragments currently override to OpenAI voices `alloy` and `echo`.
- The publish audio pipeline already hashes effective TTS settings, so changing voice/provider settings should naturally regenerate affected fragments.
- There is no explicit loudness normalization target documented for generated MP3s.

### Goal
- Select a warmer, clearer ElevenLabs voice for the main Auxilium Christianorum body.
- Preserve the prayerful tone: calm, mature, gentle, low-fatigue, and not theatrical.
- Fix the practical low-audio problem either by choosing a stronger voice, adding a documented loudness normalization step, or both.
- Keep the existing episode identity, text content, block order, role-aware fragments, RSS output, and Spotify resolver behavior stable.

### Constraints
- Do not depend on soon-to-expire ElevenLabs legacy Default voices as the long-term answer.
- Prefer a voice available through the user account's ElevenLabs library/API and capture its `voice_id` in the contract.
- Any loudness fix must be deterministic and testable without live ElevenLabs calls.
- Voice selection should be reversible by changing contract settings, not by changing prayer templates or generated text.
- Keep provider fallback working if ElevenLabs fails.

### Narrow Wedge
- Choose one production candidate voice and update Auxilium's main ElevenLabs provider settings.
- Add a small local evaluation script or documented smoke command that renders the same Auxilium excerpt with candidate voices into `artifacts/local/`.
- Add or confirm audio output normalization if generated fragments remain materially quieter than OpenAI fallback audio.
- Add tests proving voice/provider settings remain part of the fragment hash and sidecar metadata.

### Voice Recommendation
- Recommended direction: use ElevenLabs Voice Library or Voice Design to create/select a custom "warm devotional narrator" voice, then store the resulting `voice_id`.
- Avoid building on ElevenLabs legacy Default voices for this release because ElevenLabs says Default voices are being replaced and will expire on December 31, 2026.
- Candidate voice profile:
  - Gender/timbre: warm adult male baritone or warm adult female alto; choose whichever feels most natural for the Auxilium text.
  - Accent: neutral American English unless the prayer audience prefers another accent.
  - Delivery: gentle, reverent, steady, intimate, non-dramatic.
  - Pace: `0.95` to `1.0`; avoid rushing the litanies.
  - Settings: start with stability `0.65`, similarity boost `0.8`, speaker boost `true`, style `0`, speed `0.98`.
- Practical shortlist to test:
  - Option A: ElevenLabs Voice Design prompt: "A warm, reverent Catholic devotional narrator, mature adult, calm and gentle, clear diction, steady prayerful pacing, natural American English, intimate but not theatrical."
  - Option B: ElevenLabs Voice Library search for `warm narrator`, `devotional`, `calm`, `meditation`, or `audiobook`, then save the best candidate to My Voices and copy its `voice_id`.
  - Option C: Keep the current custom voice but add loudness normalization; choose this only if the voice tone is already right and the issue is purely output level.

### Non-Goals
- Rewriting Auxilium Christianorum prayer text.
- Changing the public episode id, title template, description template, RSS feed path, Notion page behavior, or Spotify lookup contract.
- Adding multi-voice dramatization beyond the current `versicle` and `response` roles.
- Backfilling all historical Auxilium episodes.
- Committing to a legacy Default voice that may disappear after 2026.

### Risks And Unknowns
- The exact current custom voice name behind `2NfTQuOn6dRQvgKuC2le` is not visible in the repo.
- ElevenLabs Voice Library availability depends on account plan, saved voices, and API access.
- A warmer voice may still render quieter than OpenAI unless the pipeline normalizes final loudness.
- Voice changes will invalidate fragment cache identities; that is desirable for regeneration, but it should be confirmed in tests before publishing.
- If the chosen voice is from the community library, licensing/availability terms may change.
