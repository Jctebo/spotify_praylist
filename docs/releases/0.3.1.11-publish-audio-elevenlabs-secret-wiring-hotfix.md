## Scope

### Problem
- The Morning Prayer ElevenLabs variant was configured to read `ELEVENLABS_API_KEY`, but the main publish workflow only exported `OPENAI_API_KEY`.
- As a result, GitHub Actions could fail with a missing ElevenLabs key even when the secret existed in repository settings.

### Goal
- Export `ELEVENLABS_API_KEY` in the main audio publish workflow so the Morning Prayer ElevenLabs contract can render in GitHub Actions.
- Document the new runtime requirement in the README.
- Add a regression test that keeps the workflow secret wiring from drifting again.

## Research

### Findings
- The publish audio workflow env block already exported `OPENAI_API_KEY`, but not the ElevenLabs secret.
- The ElevenLabs renderer reads the key from the environment, so the workflow had to provide it explicitly.
- A workflow-text regression test is the smallest stable guard for this wiring.

## Plan

### Implementation
- Add `ELEVENLABS_API_KEY: ${{ secrets.ELEVENLABS_API_KEY }}` to `.github/workflows/publish_audio.yml`.
- Add a workflow text assertion in `tests/test_publish_audio_pipeline.py`.
- Update `README.md` to mention the ElevenLabs secret requirement for local and GitHub Actions runs.
