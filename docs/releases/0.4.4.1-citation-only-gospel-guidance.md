## Scope

### Problem
- Citation-only Gospel context is useful to the LLM, but without an explicit limitation it may invent wording or specific passage details.

### Audience
- Primary user: maintainer reviewing devotional intro quality and fallback behavior.
- Secondary stakeholders: listeners receiving concise, trustworthy Gospel-aware introductions.

### Current Status Quo
- The citation is passed when present, but the prompt does not explicitly distinguish citation-only context from supplied Gospel text.

### Goal
- Preserve useful citation-aware generation while making citation-only limitations explicit.
- Success criteria: citation-only prompts tell the model not to quote, invent wording, or assert unverified details; full-text and missing-context behavior remain unchanged; regression tests cover the prompt guidance.

### Constraints
- Do not change the provider order, fallback chain, or full-text Gospel guard.
- Do not add external services or log Gospel text.

### Narrow Wedge
- Add citation-only prompt instructions and tests for citation-only, full-text, and missing Gospel states.

### Non-Goals
- Re-fetching or replacing Gospel sources.
- Reprocessing existing audio.

### Risks And Unknowns
- Citation-only generation remains less specific than full-text generation; the prompt now favors caution over fabricated detail.

### Recommended Next Step
- Implement the prompt branch, add focused tests, run the full suite, review, and ship.

## Research

- The shared prompt already receives a Gospel citation when available, while `gospel_context_quality` distinguishes citation-only input from full text.
- The existing full-text validation guard must remain unchanged; citation-only input should remain usable but explicitly bounded.

## Plan

1. Update the shared devotional intro prompt to classify citation-only context and prohibit invented quotations or unverified details.
2. Add focused regression tests asserting the citation-only guidance and preserving existing full-text/missing-context rules.
3. Run focused and full test suites, inspect the diff, and ship the micro release.
