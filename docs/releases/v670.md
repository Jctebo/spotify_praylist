2. For EVERY profile in the payload (John's saved profiles AND the three defaults, which stand as records in the same payload):
   - For each block in the profile's coreBlocks: take the block's EFFECTIVE list (stored contents if standing, else `opnStandingContents597`).

   - A profile with any migrated block is saved ONCE through the standing save route (`/api/prayer/profiles/save`, the `opnWrite604` payload shape: key · name · honorLine · coreBlocks · layers · contents), with all its blocks' contents carried (stored blocks verbatim + migrated blocks), never a partial contents object.

4. After every write lands (or none were needed): remove `opn-office-choice-v650`, set `opn-office-mig-v670`. A write failure leaves the flag unset and the legacy key standing; the next boot retries.
