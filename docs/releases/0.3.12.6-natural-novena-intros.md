# Release 0.3.12.6 — Natural Novena Intros

## Scope

### Problem

- Novena introductions fall back unnecessarily when generated prose paraphrases supplied contract metadata instead of copying it word for word.
- Deterministic fallbacks across the devotional intro profiles join metadata fragments together, which can create duplicated punctuation and ungrammatical sentences.

### Audience

- People listening to daily novena audio.
- Maintainers reviewing generated intro sidecars.

### Goal

- Accept natural, prayer-specific novena prose while retaining identity, day, and existing safety checks.
- Produce grammatical deterministic fallback prose from complete sentences for every devotional intro profile.
- Advance the policy version so stale sidecars regenerate.

### Constraints

- Preserve the existing no-length-limit policy.
- Do not weaken markdown, prompt-injection, unsupported-Scripture, or Gospel-safety checks.

### Narrow Wedge

- Remove literal-match requirements for optional novena metadata.
- Rebuild each devotional intro fallback composition and add regressions for punctuation and spoken prose.

### Non-Goals

- Rewriting novena contracts or the broader devotional generation pipeline.

### Risks And Unknowns

- Natural prose cannot be mechanically proven to reflect every metadata field; the generation prompt remains responsible for grounding optional details.

### Recommended Next Step

- Implement the focused validation and fallback changes with regression coverage across profiles.

## Research

- The July 30 St Mary MacKillop sidecar fell back because validation required its full summary as an exact substring, despite the prompt allowing a faithful paraphrase.

## Plan

- Keep day and prayer-identity validation, but remove exact-match gates for focus, summary, patronage, and calendar bridge.
- Normalize fallback source fragments into complete sentences across profiles and avoid repeating a saint name as a focus phrase.
- Bump the policy version and test both natural generated prose and fallback grammar for each profile.

## Progress

- Implemented focused validation and fallback updates with regression coverage across every devotional intro profile.
