# Release 0.4.2.6 - shared-liturgical-prayer-intros

- Status: Scoped
- Created Date: 2026-08-20
- Last Updated: 2026-08-20
- Depends On: 0.4.2.5

## Scope

### Problem

- Morning Prayer, Auxilium Christianorum, Marian Antiphon, and Daily Reflection already receive a shared daily liturgical context, but that context is not yet the requested single forward-looking observance selection.
- The current calendar brief selects a target-day anchor whenever any target-day row exists and separately chooses a nearby saint witness, which can produce a backward-looking saint that differs from the primary observance.
- The generic devotional-intro prompt still requires a saint witness and approved quotation, repeated calendar anchors, prayer identity, and profile-specific sentence limits. Daily Reflection additionally requires exactly four paragraphs, three question endings, a fixed examen vocabulary, repeated saint/quotation usage, and fixed closing lines.
- These constraints make the four openings sound formulaic and can force weak saint connections or stale biographical/quotation material instead of letting the model write a good prayer introduction.

### Audience

- Primary user: a Catholic listener who hears four daily prayer experiences and wants them to feel like distinct, natural invitations into prayer.
- Secondary stakeholders: the publishing and audio pipelines, which need one coherent daily observance, bounded spoken text, safe fallbacks, and compatible sidecars.

### Current Status Quo

- `build_saint_centered_theme_brief()` scans a D-3 through D+9 window, chooses a target-day-first anchor, and independently selects a nearby saint witness, preferring an approved quotation.
- `build_daily_liturgical_context()` adapts that brief into the shared runtime payload consumed by the four prayer families.
- `devotional_intro.py` generates Morning Prayer, Auxilium Christianorum, and Marian Antiphon openings through prayer profiles, then validates supplied anchors, saint names, quotations, identity, minimum lengths, and Gospel usage.
- `ignatian_reflection.py` generates Daily Reflection with a rigid four-paragraph Ignatian/examen contract and a deterministic fallback based on the same context.
- Runtime caching already provides a useful boundary for sharing context and avoiding duplicate generation within a publish job, but the cache key and shared payload must remain date/context-safe as selection metadata changes.

### Goal

- Establish one deterministic Catholic liturgical-calendar selection for each local date, calendar, locale, and rule set, and pass that same selected observance to all four prayer generators.
- Check today first for a suitable General Roman Calendar observance; otherwise search only the next nine calendar days and rank Solemnity, Feast, Obligatory Memorial, then Optional Memorial before proximity, with sooner date breaking equal-rank ties.
- On feast/solemnity/memorial days, keep the celebration actually being observed as the shared primary observance. On non-feast days, permit the deterministic selector to use a meaningful upcoming observance without allowing an older date or an obscure optional saint to displace the preferred calendar result.
- Give the LLM freedom over wording, paragraphing, transitions, spiritual emphasis, and how the observance illuminates each prayer. The LLM may select from supplied deterministic context only in the sense of choosing a connection; it must not replace the selected observance or invent another date.
- Make the four outputs recognizably different while preserving one quiet shared spiritual theme:
  - Marian Antiphon: connect the observance to the antiphon's Marian or Christian disposition and transition naturally into the antiphon.
  - Morning Prayer: connect the observance to offering the day, duties, vocation, family, work, charity, discipline, or attentiveness to grace, ending with one simple disposition.
  - Auxilium Christianorum: connect the observance to Christ's victory, grace, holiness, perseverance, protection of family and vocation, repentance, humility, and Mary's help without sensationalizing spiritual warfare, ending with one simple intention.
  - Daily Reflection: use the observance as a concise spiritual lens for ordinary Christian life and one central theme across prayer, relationships, work, stewardship, health, rest, charity, conversion, perseverance, and trust in God while preserving the existing reflection purpose.

### Constraints

- Reproducibility is a hard requirement: the same local date, timezone, calendar data, locale, and selection rules must yield the same shared observance for every prayer and every rerun. Runtime LLM randomness must not choose the calendar observance.
- The current user wording asks for “some randomness” and different upcoming saints during the day, but that conflicts with a single shared selected observance. This scope treats the shared-selection requirement as authoritative; natural variation belongs in prose, not saint selection. If variety among equivalent candidates is desired, it must use a deterministic date-seeded tie-breaker and remain identical across all four prayers.
- Timing must be explicit and accurate: “Today the Church celebrates…” for a current observance, and “As we approach [observance] on [actual date]…” for a future one. No upcoming celebration may be described as today.
- General Roman Calendar observances should be preferred. Reliable calendar data and liturgical rank remain application-owned inputs; the LLM must not browse, verify, or override them during generation.
- The existing spoken/audio and sidecar contracts should remain compatible unless a test demonstrates that their current fields cannot express natural introductions or reflections.
- The system must retain bounded, nonempty, plain spoken output and deterministic fallback behavior. Removing rigid style checks must not remove malformed-output, prompt-commentary, unsupported-Scripture, or unsafe-length protections.
- Novena-specific introductions and unrelated devotional/image/Spotify flows are not part of this scope.

### Narrow Wedge

- Replace the shared calendar brief's target-day-plus-separate-witness behavior with one explicit selected-observance record containing name, date, rank, season, timing, source, and supporting forward candidates.
- Thread that record through the existing shared daily context into the four targeted generators.
- Rewrite the three devotional-intro profiles and Daily Reflection prompt as prayer-specific creative briefs with natural prose freedom, while retaining only hard identity, calendar-timing, safety, audio-boundary, and Catholic-content requirements.
- Relax validators and deterministic fallbacks in the smallest compatible way: accept varied paragraphing and sentence structure, stop requiring an approved quotation or fixed saint-witness placement when none is necessary, and preserve each prayer's essential transition/closing behavior where the audio contract requires it.
- Add focused tests for calendar rank/date selection, shared context identity, today/upcoming wording, deterministic repeatability, distinct prayer-specific prompts, natural prose acceptance, malformed/safety rejection, and fallback compatibility.

### Prompt Requirements

#### Shared Prompt Contract

- State that the supplied local date, liturgical season, selected observance, observance date, liturgical rank, and supporting calendar facts are authoritative.
- Use the same selected saint, feast, solemnity, memorial, or other observance in all four prayer outputs for the date.
- Do not ask the model to search backward, choose a replacement observance, verify dates independently, or invent a liturgical rank, saint, feast, quotation, Scripture citation, or biographical fact.
- Explain the selection preference in the prompt context: check today first; if no suitable observance exists, look through the next nine calendar days; prefer the General Roman Calendar; rank Solemnity, Feast, Obligatory Memorial, then Optional Memorial; let rank take precedence over proximity; and use the sooner date for equal ranks.
- Clearly state the timing in natural prose:
  - Current observance: “Today the Church celebrates the [rank] of [name]…”
  - Future observance: “As we approach the [rank] of [name] on [actual date]…”
- Never describe an upcoming observance as though it were celebrated today.
- Establish the shared observance and timing naturally without repeating the full calendar-selection explanation in every prayer.
- Treat the observance as a spiritual guide rather than a historical subject. Explain meaningful connections and omit forced connections.
- Preserve a quiet common spiritual theme across the four outputs while allowing different wording, emphasis, paragraphing, transitions, and sentence rhythm.
- Return concise plain spoken prose suitable for immediate prayer and audio narration. Avoid headings, Markdown, production commentary, prompt echoing, unnecessary biography, sensationalized spiritual warfare, and academic explanation.
- Questions may be used when spiritually appropriate, especially in Daily Reflection, but the prompt must not force identical rhetorical patterns across all four prayers.

#### Marian Antiphon Prompt

- Write a brief, natural introduction of approximately one to three paragraphs.
- Connect the selected observance to the spiritual character of the Marian Antiphon.
- When the observance is not especially Marian, connect its witness to the Christian disposition expressed by the antiphon rather than inventing Marian associations.
- Keep the focus on Christ, Mary, grace, faith, hope, obedience, joy, or another genuine connection supplied by the observance.
- End with a short, natural transition into the Marian Antiphon itself.

#### Morning Prayer Prompt

- Write a brief, natural introduction of approximately one to three paragraphs that places the beginning of the day in the light of the selected observance.
- Connect the observance's life, teaching, vocation, martyrdom, or witness to beginning the particular day before God.
- Draw naturally from offering the day, fidelity to duties, vocation, work, family, charity, humility, courage, discipline, surrender to Providence, or attentiveness to grace.
- Give the listener one simple spiritual disposition or intention to carry into the day.
- End with a natural transition into Morning Prayer.

#### Auxilium Christianorum Prompt

- Write a brief, natural introduction of approximately one to three paragraphs connecting the selected observance to Auxilium Christianorum.
- Use appropriate themes such as confidence in Christ's victory, spiritual protection, perseverance in temptation, fidelity under trial, resistance to discouragement, repentance, humility, dependence upon grace, protection of family and vocation, Mary as Help of Christians, and the intercession of the saints.
- Keep the emphasis on Christ's victory, grace, holiness, confidence, and perseverance. Do not sensationalize evil or spiritual warfare.
- Give the listener one simple intention or disposition to carry into the prayers.
- End with a natural transition into the Auxilium Christianorum prayers.

#### Daily Reflection Prompt

- Use the same selected observance as a spiritual lens for the Daily Reflection.
- Begin with a short, natural connection between the observance and ordinary Christian life. Do not give a long biography.
- Identify one central spiritual theme drawn from the observance's life, teaching, vocation, martyrdom, or the mystery being celebrated.
- Apply that theme to suitable areas such as prayer and interior life, marriage and family, fatherhood and relationships, work and vocation, financial stewardship, health and discipline, recreation and rest, charity, humility, conversion, perseverance, trust in God, ordering desires, love of Christ, and fidelity to ordinary responsibilities.
- Preserve the existing Daily Reflection purpose: a contemplative, practical reflection that leads the listener toward examination, conversion, gratitude, and trust in God.
- Allow the existing audio structure to remain only where technically necessary for pauses, segments, closing prayer, and feed metadata; do not force the model to sound like a fixed four-paragraph template when natural prose can satisfy the audio boundary.
- End with a prayerful conclusion appropriate to the existing Daily Reflection format, without requiring an approved quotation unless one is supplied and genuinely useful.

### Detailed Writing Guidance To Preserve

The implementation should carry the following detailed guidance into the prompt formation rather than reducing it to generic instructions.

#### Calendar Selection And Shared Observance

- Determine today's actual local date and liturgical season before generating any prayer material.
- Check today's General Roman Calendar for an appropriate solemnity, feast, obligatory memorial, optional memorial, or saint.
- If there is no suitable observance today, look ahead through the next nine calendar days.
- When looking ahead, prioritize liturgical rank in this order:
  1. Solemnity
  2. Feast
  3. Obligatory Memorial
  4. Optional Memorial
- Liturgical rank takes precedence over proximity. If two appropriate observances have the same rank, choose the one occurring sooner.
- Prefer observances on the General Roman Calendar unless a major universal celebration clearly takes precedence.
- The model may be given several relevant forward candidates or supporting details, but the application-owned shared selection remains authoritative for all four prayers.
- Do not let approved-quotation availability, a preferred saint biography, or a model-generated theme cause a lower-ranked or older saint to displace the selected observance.
- On a feast day, solemnity, or memorial, stay with the saint or observance actually being celebrated.
- On a non-feast day, use a meaningful upcoming observance when one is selected by the deterministic rules, but do not imply that it is being celebrated today.
- Use reliable Catholic calendar data for dates and ranks when necessary. The model must not independently alter or verify the application-owned selection during generation.

#### Timing Language

- Before the prayer content begins, identify the selected saint or observance naturally.
- Be precise about whether the observance is today or upcoming.
- For a current observance, use natural wording such as: “Today the Church celebrates the Memorial of [name]…”
- For a future observance, use natural wording such as: “As we approach the Feast of [name] on August 24…”
- If the selected observance is upcoming, state both its name and its actual calendar date.
- Never imply that an upcoming feast, memorial, or solemnity is being celebrated today.
- Do not repeat the full calendar-selection explanation before every prayer. Establish the timing clearly once, then allow later introductions to refer to the same saint or feast naturally without sounding repetitive.

#### Overall Style Across All Four Sections

- Keep the tone distinctly Catholic, contemplative, reverent, practical, and natural.
- Use the saint or feast as a spiritual guide for the day, not merely as a historical subject.
- Avoid unnecessary biographical detail.
- Do not force weak connections between the observance and a prayer.
- Keep each introduction concise enough that it genuinely functions as an introduction to prayer.
- Allow a common spiritual theme to quietly connect the prayers throughout the day.
- Avoid making every introduction sound structurally identical.
- Give the LLM freedom to choose good-sounding wording, paragraphing, transitions, emphasis, and sentence rhythm.
- The four outputs should not simply repeat the same paragraph four times. They should share the observance and broad theme while adapting the connection to each prayer.
- Do not ask the listener questions before generating the material. Determine the date, weekday/season context, observance, timing, and prayer context from the supplied inputs.
- Avoid academic exposition, filler, forced saint name repetition, sensationalized evil or spiritual warfare, invented quotations, unsupported Catholic claims, unsupported Scripture citations, and production commentary.

#### Theme Guidance And Daily Variety

- Establish one quiet shared spiritual theme for the day from the selected saint, feast, solemnity, memorial, liturgical season, or mystery being celebrated.
- The shared theme should unify the four prayers without making them interchangeable. It is a connective thread, not a repeated slogan or taxonomy label.
- Let the LLM select the most spiritually meaningful emphasis from the supplied observance context rather than forcing a predetermined virtue onto every day.
- Suitable themes may include:
  - offering the day to God;
  - fidelity to ordinary duties;
  - vocation and work;
  - family and relationships;
  - charity and service;
  - humility;
  - courage;
  - discipline;
  - surrender to Providence;
  - attentiveness to grace;
  - confidence in Christ's victory;
  - spiritual protection grounded in grace;
  - perseverance in temptation or trial;
  - repentance and conversion;
  - dependence upon God;
  - prayer and interior life;
  - trust in God;
  - ordering of desires;
  - love of Christ;
  - fidelity to ordinary responsibilities;
  - joy, hope, obedience, faith, or gratitude when genuinely supported by the observance.
- Adapt the shared theme to each prayer rather than repeating the same application:
  - Marian Antiphon should express the theme through Mary's faithful disposition and the character of the antiphon.
  - Morning Prayer should turn the theme toward the offering and responsibilities of the coming day.
  - Auxilium Christianorum should turn the theme toward grace, Christ's victory, protection, holiness, and perseverance.
  - Daily Reflection should turn the theme toward interior examination and ordinary Christian life.
- On a feast, solemnity, or memorial, keep the celebrated saint or observance central and let its actual witness determine the theme. Do not replace it with a more convenient upcoming saint.
- On a non-feast day, the calendar context may include several appropriate upcoming saints or feasts. The selector may use their rank and date to determine the shared observance, while the LLM may draw varied spiritual emphasis from the supplied supporting context without changing the selected observance.
- The original request to “mix up the introductions for different upcoming saints throughout the day” is retained as a desired variety goal for prose and emphasis, but it cannot mean selecting different saints per prayer while the shared-observance and deterministic requirements remain in force.
- If a future product decision requires one different upcoming saint per prayer, that must become a separate selection mode with its own deterministic mapping and is outside this scope.

#### Marian Antiphon — Complete Brief

- Write a brief, natural introduction of approximately one to three paragraphs.
- Briefly connect the selected saint or feast with the spiritual character of the Marian Antiphon.
- If the saint is especially associated with Mary, Marian devotion, the Incarnation, the Resurrection, obedience, or Mary as Help of Christians, use that connection when it is genuine.
- If the saint is not especially associated with Marian devotion, do not manufacture a specifically Marian biography or claim. Instead, connect the saint's witness to the Christian disposition expressed by the antiphon.
- Depending on the antiphon and season, this disposition may involve faithful receptivity, joy, hope, trust, obedience, gratitude, Easter confidence, the mystery of the Word made flesh, or perseverance in grace.
- Keep the introduction centered on the prayer about to be prayed, not on a general saint biography.
- End with a short, natural transition into the Marian Antiphon.

#### Morning Prayer — Complete Brief

- Write a brief, natural introduction of approximately one to three paragraphs.
- Place the beginning of the day in the light of the selected saint or feast.
- Connect the saint's life, teaching, vocation, martyrdom, or spiritual witness to how the listener might begin this particular day.
- Appropriate connections include:
  - offering the day to God;
  - fidelity to today's duties;
  - vocation;
  - work;
  - family;
  - charity;
  - humility;
  - courage;
  - discipline;
  - surrender to Providence;
  - attentiveness to grace.
- Do not list these themes mechanically. Choose the one or two that genuinely arise from the selected observance and the beginning-of-day setting.
- Give the listener one simple spiritual disposition or intention to carry into the day.
- The disposition should be practical enough to live in ordinary responsibilities, relationships, work, prayer, or family life.
- End with a natural transition into Morning Prayer.

#### Auxilium Christianorum — Complete Brief

- Write a brief, natural introduction of approximately one to three paragraphs.
- Connect the selected saint or feast to the themes of Auxilium Christianorum.
- Appropriate connections include:
  - confidence in Christ's victory;
  - spiritual protection;
  - perseverance in temptation;
  - fidelity under trial;
  - resistance to discouragement;
  - repentance;
  - humility;
  - dependence upon grace;
  - protection of family and vocation;
  - Mary as Help of Christians;
  - intercession of the saints.
- Keep the emphasis on Christ's victory, grace, holiness, confidence, and perseverance.
- Do not sensationalize evil, demons, spiritual warfare, or danger.
- Connect protection to dependence on Christ, conversion, holiness, family, vocation, and faithful perseverance rather than fear.
- Give the listener one simple intention or disposition to carry into these prayers.
- End with a natural transition into the Auxilium Christianorum prayers.

#### Daily Reflection — Complete Brief

- Use the same saint or feast as a spiritual lens for the Daily Reflection.
- Begin with a short, natural connection between the observance and ordinary Christian life.
- Do not give a long biography or turn the opening into a historical summary.
- Identify one central spiritual theme from the saint's life, teaching, vocation, martyrdom, or the mystery being celebrated.
- Use that theme to guide reflection on one or more areas such as:
  - prayer and interior life;
  - marriage and family;
  - fatherhood and relationships;
  - work and vocation;
  - financial stewardship;
  - health and discipline;
  - recreation and rest;
  - charity;
  - humility;
  - conversion;
  - perseverance;
  - trust in God;
  - ordering of desires;
  - love of Christ;
  - fidelity to ordinary responsibilities.
- Choose an area that makes the selected observance spiritually relevant today rather than forcing a generic examination of every area.
- Preserve the existing Daily Reflection purpose and recognizable structure, but treat the structure as a guide for a coherent reflection rather than a demand for identical paragraph mechanics.
- The reflection should remain contemplative, practical, intimate, and suitable for spoken audio.
- It should lead the listener toward prayer, interior examination, gratitude, conversion, trust in God, and a faithful next step.
- Use questions, examen language, or pauses where they serve the reflection, but do not force every prayer section to use the same question pattern.
- End with a prayerful conclusion appropriate to the existing Daily Reflection format.

#### Freedom Versus Hard Requirements

- Soft writing guidance: approximate paragraph count, natural transitions, sentence variety, degree of biography, number of practical applications, number of questions, exact location of the saint's name, and whether a quotation is used.
- Hard content requirements: use the supplied prayer identity, use the supplied shared observance and timing accurately, distinguish today from upcoming, remain faithful to Catholic teaching and supplied facts, maintain a meaningful prayer transition, and avoid invented citations or quotations.
- Hard technical requirements: return nonempty bounded plain prose, preserve compatible audio boundaries and sidecar fields, reject prompt or schema commentary, reject unsupported Scripture citations, and use deterministic fallback text when generation fails.
- A saint quotation is optional. When a quotation is supplied and used, reproduce it accurately and attribute it; never require a quotation merely because one exists in legacy context.
- The model may omit a saint name or observance reference from a later sentence when repeating it would sound unnatural, provided the prayer introduction as a whole clearly establishes and meaningfully uses the shared observance.

### Non-Goals

- Allowing the LLM to select a different saint or feast for each prayer.
- Introducing nondeterministic calendar selection, unseeded randomness, or model-generated liturgical facts.
- Rewriting the fixed canonical prayer bodies, Auxilium source text, Marian antiphon text, Morning Prayer sequence, or audio fragment architecture.
- Removing all validation or allowing arbitrary long, empty, instructional, citation-inventing, or prompt-echoing output.
- Designing a new liturgical-calendar provider or replacing Romcal beyond the selection behavior required here.
- Applying this prompt-freedom change to Rosary, novena, image, or unrelated devotional generators.

### Risks And Unknowns

- The largest product ambiguity is whether the user ultimately wants one shared observance or different upcoming saints per prayer. Those requirements cannot both be deterministic and shared; implementation should preserve one shared observance unless the user explicitly changes that decision.
- The existing saint-witness quotation catalog is sparse. Requiring quotations would continue to bias selection toward a few saints, so the new scope should treat quotations as optional and never let quotation availability outrank liturgical rank.
- Daily Reflection's current four-paragraph/examen validator is tightly coupled to pause timing and fallback output. Relaxing prose shape without losing a readable, contemplative audio segment needs explicit acceptance tests.
- A forward-looking selector may change existing titles, descriptions, sidecar metadata, and daily audio text on ordinary days. The rollout must verify today, upcoming, rank tie, no-candidate, and provider-failure cases.
- Model freedom can produce weak or repetitive connections even when the calendar selection is correct. Prompt guidance and bounded fallback quality need evaluation across all four prayer types rather than relying only on schema validity.

### Failure Modes

- Calendar provider unavailable: use the existing deterministic seasonal/weekday fallback, mark the fallback reason, and never invent a saint or date.
- No suitable observance today or in the next nine days: use a deterministic liturgical-season/weekday fallback with accurate timing rather than a retrospective saint.
- Equal-ranked candidates: stable date/name/tie-break ordering keeps all prayers and reruns identical.
- LLM invents an observance, wrong date, unsupported quotation, Scripture citation, or prompt commentary: validator rejects it, retries once with correction, then uses deterministic fallback.
- One prayer's generation fails: only that prayer falls back; all four retain the same shared observance context.
- Contract or audio assembly fails: the production workflow stops before deployment and logs the contract/entry failure.
- Production sync or Pages deployment fails after local output succeeds: retain generated artifacts for diagnosis, report the failed deployment stage, and do not claim production completion.
