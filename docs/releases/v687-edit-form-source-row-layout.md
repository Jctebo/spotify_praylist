### §2.1 The layout causes, grounded

The source row's HTML (`opnSourceRowHtml686`, client.ts:24091) is one `.row` flex line: pin span · `<span class="grow">` (name + tag) · `.switch591` button · `<select data-p686day>`. The seats:

1. **The select's width.** The global form rule (ui.ts:293) sets `select { width:100%; … }`. The v686 row rule (ui.ts:538) sets `.p686srcrow select { flex:0 0 auto; margin-left:8px; min-height:32px; }` — it overrides the flex but **never the width**, so the flex item's basis resolves from `width:100%`: the select takes the full row width as its base size and, with `flex-shrink:0`, keeps it. That is the over-long drop down in both screenshots (its chevron lands off the first screen; the page scrolls sideways to reach it).
2. **The scrunched title.** `.row` is `display:flex` (ui.ts:296) and `.grow` is `flex:1` (ui.ts:297) with **no `min-width:0`** on this row class (the only `min-width:0` grow rule is `.card.trow .grow`, ui.ts:255 — a different row). With the select claiming 100% and the switch at its fixed size, the title's flex space is the negative remainder; the span collapses to its min-content — the longest single word ("Invitatory" / "Readings") — and wraps word-per-line. Exactly the screenshot.
3. **The office segtoggle overlap.** The office contents row (`opnEditGroupHtml609`, client.ts:27135–27144) puts the v670 toggle as a bare `<span class="segtoggle">` — the **base** `.segtoggle` dress (ui.ts:433–435: `display:flex; margin:0 0 12px`, buttons `flex:1`, 15px, 8px padding) — not the compact `.segtoggle.pill` dress (ui.ts:442–444, `flex:none`). In the row's flex line it stands after the label, the two 40×44 ▲▼ buttons, and before ⋮/Remove: the line's min-content (label min-content + move buttons + a two-button toggle at full dress + ⋮ + Remove) exceeds the card at phone width, and the toggle — margin-bottom 12px inside a center-aligned line, its buttons flexing — paints across the label's wrap area. The screenshot's Morning Prayer row is this line.

**The fix (with §2.8's dress change):** the select leaves the row (frequency → menu), retiring seat 1 with it; the source row's `.grow` gains `min-width:0` so the title flexes and wraps inside its own column; the office toggle takes a compact Edit-form seat (§2.9). The harness (§2.10) measures the result at 390px: no horizontal overflow anywhere in the form, the title box at its natural width, every control box inside its row box.

### §2.7 The ⋮ menu and Disable

**Disable — contents item (the store shape).** Today a contents item has no per-item off state. **Shape: an `off` field on the item object** (`{kind, key, …, off: 1}`; absent = on) — the same way `side` rides an office item.
