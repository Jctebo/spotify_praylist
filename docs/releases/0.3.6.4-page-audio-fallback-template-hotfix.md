# Release 0.3.6.4: Page-Audio Fallback Template Hotfix

## Scope

### Problem
- After v0.3.6.3 fixed the missing config-file read, the remote Morning Prayer page-audio workflow reached generation and failed on a stale fallback resolver: `petition-church`.
- The built-in fallback Morning Prayer contract references `config/publish/templates/morning-prayer/petition-church.txt`, but that file is no longer checked in.

### Audience
- Repo maintainer running the remote Morning Prayer page-audio workflow.

### Current Status Quo
- `Validate rclone remote` now passes.
- `Generate page audio on runner` logs `page_audio_error title=Morning Prayer error=Morning Prayer content file is missing or empty for resolver 'petition-church'.`
- Sync fails because no Morning output folder is produced after generation records `failed=1`.

### Goal
- Keep the built-in fallback Morning Prayer contract synchronized with the current checked-in Morning Prayer templates.
- Add regression coverage so fallback file resolvers cannot point at missing files.

### Constraints
- Do not recreate legacy template files just to satisfy stale fallback data.
- Do not change the external Notion row shape.
- Keep the change focused to the fallback contract and tests.

### Narrow Wedge
- Remove the stale `petition-church` fallback resolver and renumber the remaining built-in resolvers.
- Add a test that loads the default fallback contract and asserts every `kind=file` resolver path exists.

### Non-Goals
- Reworking the page-audio generation model.
- Fixing `Publish Prayer Text` Notion configuration.

### Risks And Unknowns
- The remote workflow may expose another live data dependency after this fallback mismatch is fixed.

### Recommended Next Step
- Implement the fallback contract cleanup, run focused/broader tests, ship, and rerun the remote workflow.

## Research

- Remote run `27481939888` passed `Validate rclone remote` and `Generate page audio on runner` executed.
- The generation log reported `Morning Prayer content file is missing or empty for resolver 'petition-church'.`
- `config/publish/templates/morning-prayer/` contains `petition-sanctification-of-the-church.txt` and other active petition files, but not `petition-church.txt`.
- The published Morning Prayer contract in `config/publish/contracts/morning-prayer.json` no longer includes a `petition-church` block.
