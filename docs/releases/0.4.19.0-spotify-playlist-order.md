## Scope

### Problem
- Spotify playlists contain extra entries and do not follow the intended sequence because repo-owned playlist arrays drifted from the intended enabled playlist rows.

### Audience
- Primary user: maintainer of the Spotify playlist refresh.
- Secondary stakeholders: listeners using the four Spotify playlists.

### Current Status Quo
- Playlist JSON currently includes 13 Midday, 8 Morning, and 5 Night contracts.
- Read-only review of the Notion `Opus Dei` database shows the intended enabled queues are 5 Midday, 7 Morning, 4 Night, and 2 Sunday contracts, ordered by `Order` and grouped by `Output Folder`.

### Goal
- Make checked-in playlist contracts match enabled source rows in exact order.
- Add regression coverage pinning all four queue memberships and sequences.
- Production refresh must consume the corrected repo-owned contracts with no Notion runtime dependency.

### Constraints
- Keep Notion read-only as reference data; do not restore integration credentials or runtime hooks.
- Preserve playlist IDs and queue contract definitions.
- Update production only after the change is reviewed and merged.

### Narrow Wedge
- Correct membership/order in the four playlist JSON files and test the exact resulting arrays.

### Non-Goals
- Editing Notion rows or changing prayer content and contract resolution behavior.
- Refreshing unrelated audio, wallpaper, or website production jobs.

### Risks And Unknowns
- Dynamic resolvers can return no playable item for a given day; playlist contract tests verify membership/order, while production job logs will report actual written counts.

### Recommended Next Step
- Review the config diff, run focused playlist tests, merge the release PR, then dispatch and verify the production Spotify refresh.

## Research

- `jobs/playlist/spotify_contracts.py` loads `config/spotify/playlists/*.json` as ordered contract arrays; the refresh path is repository-driven and Notion-free.
- The live `Opus Dei` data source has `Name`, `Order`, `Enabled`, and `Output Folder` properties. Querying enabled rows grouped by folder and sorted by order yields 7 Morning, 5 Midday, 4 Night, and 2 Sunday rows.
- Every enabled row maps to an existing Spotify contract; the extra existing playlist entries are not enabled for any playlist in the source list.
