## Scope

### Problem
- The repo had two Morning Prayer publish contract files that represented the same ElevenLabs-backed variant.
- That split made the canonical Morning Prayer contract name ambiguous and left a duplicate file on disk.

### Goal
- Keep only the ElevenLabs-backed Morning Prayer contract under the canonical `config/publish/contracts/morning-prayer.json` filename.
- Remove the sibling `morning-prayer-elevenlabs.json` file.
- Keep the existing Morning Prayer text and audio job behavior intact while making the filename canonical.

## Research

### Findings
- `jobs/publish/contracts.py` loads every JSON file in `config/publish/contracts/`, so the file rename is the source of truth.
- The Morning Prayer contract can keep its existing `entry_id`, provider list, and text/audio settings after the rename.
- The publish tests already cover contract discovery, fragment expansion, and audio pipeline output, so the rename can be verified end to end.

## Plan

### Implementation
- Rename the ElevenLabs-backed contract into `config/publish/contracts/morning-prayer.json`.
- Delete `config/publish/contracts/morning-prayer-elevenlabs.json`.
- Update the publish contract and audio pipeline tests to expect the canonical Morning Prayer filename and episode ids.
- Run the targeted publish test suite to confirm the rename did not change runtime behavior.
